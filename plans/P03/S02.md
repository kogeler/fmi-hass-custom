## Objective

Replace Nominatim address enrichment with local per-entry distance, initial bearing, and compass
direction; enforce the configured radius as an inclusive circle; remove geopy and its transitive
runtime graph; and publish the frozen state/attribute schema.

## Baseline and evidence

- The former parser admitted square-bbox corner observations outside the configured radius.
- Geopy was used only by the lightning distance/geocoding path. No config-flow place selection
  depended on Nominatim: place search and final location validation use FMI.
- The old entity exposed a reverse-geocoded address or raw strike coordinates as native state and
  `location`, and attributed address data to OpenStreetMap.
- S00 reference vectors established sub-millimetre parity between Home Assistant's local WGS84
  helper and the prior geopy distance for applicable vectors.

## Changes made

- Added a typed, network-free lightning geometry boundary with validated coordinates, Home
  Assistant WGS84 distance, normalized spherical initial bearing, eight half-open compass sectors,
  explicit coincidence, and failure/non-convergence rejection.
- Applied the inclusive unrounded circular radius after FMI's square bbox prefilter.
- Replaced candidate/final `location` data with numeric `distance`, optional `bearing`, and stable
  `direction`; raw strike coordinates remain transient parser inputs only.
- Changed the non-empty state to `{DIRECTION} · {distance:.1f} km`, retained FMI attribution only,
  and aligned the primary and every `OBSERVATIONS` row to the same coordinate-free schema.
- Deleted the Nominatim client, cache, global lock/rate timestamp, service constants, exception
  handling, fallback, OpenStreetMap attribution, and obsolete tests.
- Removed geopy from PEP 621 and the integration manifest, regenerated both affected hash locks,
  and verified that geographiclib disappeared transitively without a replacement dependency.
- Updated current maintenance contracts and dependency/security tests to describe and enforce the
  local geometry boundary.

Post-completion contract review added D014 and superseded only the state ordering implemented in
this historical session. Current presentation is `{distance:.1f} km · {DIRECTION}`; attributes,
geometry, source behavior, and identity are unchanged.
