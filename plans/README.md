# Completed-Plan Archive

This directory contains dated execution records, not current requirements or runbooks. Commands,
paths, versions, baselines, and conclusions inside a completed plan describe the repository at that
plan's recorded point in time and may now be obsolete.

Use the [contract catalog](../docs/contracts/README.md) for current normative behavior,
`AGENTS.md` for current agent policy, and [maintenance documentation](../docs/maintenance/) for
current procedures. Preserve completed plan material as historical evidence; do not update it merely
to match later implementation changes.
