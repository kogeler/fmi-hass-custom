## Root causes and decisions

- `async-timeout` is unnecessary on the supported Python and had no remaining reverse dependency, so the integration now uses the standard library.
- `requests` and `voluptuous` remain available through exact Home Assistant 2026.7.4 requirements; `xmltodict` is owned by FMI client 1.0.0. They were removed only from the human-maintained direct list, not forced into the manifest.
- Helper releases 0.13.349 and 0.13.350 target Home Assistant 2026.8 prereleases. Version 0.13.348 remains selected because it is the newest helper matching current stable HA 2026.7.4.
- Home Assistant pins vulnerable Pillow 12.2.0 and PyJWT 2.12.1 exactly. The owner accepted this temporary risk for private testing rather than overriding Core metadata; `TODO.md` defines the stable-upstream trigger and removal checks.
- The base image's pip 25.3 advisories were in repository control and were addressed by upgrading to pip 26.2 in lock, development, and CI environments.
