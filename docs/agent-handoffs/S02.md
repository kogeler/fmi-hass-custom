## Objective

Build a deterministic offline FMI fixture corpus and characterize the dependency contract and current public entity behavior before S03 upgrades dependencies.

## Changes made

- Added compact synthetic JSON fixtures for a 49-hour forecast across three Europe/Helsinki dates, month/year boundaries, the DST jump, late-starting precipitation, `None`/NaN values, observation data, empty results, high latitude, and client/server/parse errors.
- Added synthetic lightning and sea-level success/malformed XML payloads plus fixture metadata that prohibits private coordinates and documents the metadata required for any future captured FMI public data.
- Added deterministic builders that validate every consumed weather field and construct the installed client's real `Value`, `WeatherData`, `Weather`, and `Forecast` models.
- Added a narrow async fake for exactly the weather, forecast, and observation methods consumed by the integration.
- Added dependency contract tests for consumed model fields, async signatures, UTC-aware timestamps, exceptions, empty results, and the actual `WindGust` to `wind_gust` mapping.
- Added public entity characterization for current weather, hourly forecast, Europe/Helsinki DST/month/year grouping, missing values, observation gusts, lightning, and sea level.
- Added five documented strict `xfail` tests for incorrect daily forecast regression, polar sunrise/sunset regression, S08 `Value(None)` handling, and S09 malformed lightning/sea-level isolation.

## Root causes and decisions

- The owner explicitly authorized S02 to start before the S01 commit and will create one combined owner commit.
- `fmi-weather-client==0.7.0` represents `Value`, `WeatherData`, `Weather`, and `Forecast` as `NamedTuple` classes; timestamps parsed from FMI are UTC-aware.
- The current client maps the WFS `WindGust` value to `WeatherData.wind_gust` in m/s. Its legacy `wind_max` field is intentionally unsupported and normally contains `None`.
- Decision D008 uses synthetic fixture specifications that build real dependency models. Raw live captures were unnecessary and would add licensing/privacy review cost; `SimpleNamespace` fixtures would not protect S03 from model-shape changes.
- A generated `start`/`count` hourly-series form keeps the required 49-hour corpus compact while still producing every deterministic hourly sample.
