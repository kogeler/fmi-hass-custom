## Objective

Make optional lightning and sea-level features bounded, independently available, robust against malformed external data, and compliant with current Home Assistant async and public-geocoder usage requirements while delivering the configurable lightning maximum-age enhancement and a zero-error mypy baseline.

## Changes made

- Added a translated 1-1440 minute lightning maximum-age option with a lazy backward-compatible 1440-minute default, an inclusive cutoff, and a matching FMI query range.
- Replaced synchronous optional-source HTTP with Home Assistant's shared aiohttp session, bounded timeouts and payload reads, HTTP/error classification, and no update-level retries.
- Validated aligned lightning arrays, coordinates, timestamps, strike counts, finite values, supported sea-level records, and aware UTC output structures.
- Isolated optional-source availability, stale-data clearing, and recovery from current weather, observation, and forecast availability.
- Moved XML parsing and reverse geocoding to the Home Assistant executor; added cached, process-rate-limited, best-effort Nominatim enrichment with raw-coordinate fallback and OpenStreetMap attribution.
- Resolved the four inherited parser type errors, bringing production mypy diagnostics to zero.
- Documented optional-source behavior and significant release changes, and added deterministic malformed/error fixtures and regression coverage.

## Root causes and decisions

- Optional HTTP used blocking `requests.get` through coarse executor wrappers and discarded the shared Home Assistant session. Shared aiohttp requests now make cancellation, timeout, status, and response-size behavior explicit.
- Lightning's loop deadline multiplied seconds by 1000 before adding it to `time.time()`, and timestamps moved through host-local strings. Bounded input replaces the loop deadline, while source epochs and exposed structures remain aware UTC datetimes.
- Parallel FMI arrays were merged by index without a complete length contract. Unequal arrays now reject the response, while malformed individual aligned rows are dropped safely.
- The previous one-day lightning query was implicit. A 1440-minute default preserves that behavior without rewriting entries, and the exact cutoff retains a strike whose age equals the configured limit.
- Repeated public Nominatim calls were not compatible with its usage policy. Address data is optional, cached, limited to one unseen coordinate per update and one process-wide request per 15 seconds, and never controls FMI sensor availability.
